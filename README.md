# Sanjana S Katti — Portfolio

Responsive React + Vite portfolio with a warm editorial visual style.

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install` and then `npm run dev`.

## Production build
Run `npm run build`; Vite writes the production site to `dist/`.

## Deploy with Vercel
Import the GitHub repository in Vercel. Use the Vite preset, build command `npm run build`, and output directory `dist`.
